# ADR 0130: Distinguishability before structural comparison

- Status: Accepted planning and compatibility constraints; new APIs unimplemented
- Date: 2026-09-06

## Decision

Adopt the [revised roadmap](../structural-geometry/REVISED_ROADMAP.md) after a
section-by-section [analysis](../structural-geometry/REVISION_ANALYSIS.md) of the
new user-supplied research/site proposal. Preserve both proposals verbatim.
Keep implemented projection, Forman, Ollivier and rational shadow flow as the
current baseline; change the order of remaining work.

Capture baseline identities, supplement the newly requested flow controls,
then add compatible metric providers, explicit observation regimes, immutable
probes, response-only signatures and a fixed-domain pseudometric. Test geometric
added value before directed persistence, higher-order and cross-domain work.
The public result-bearing Lab remains downstream of the research gates.

## Required corrections to the proposal

Keep intra-graph directed geometry separate from symmetric inter-structure
comparison. Preserve source-parent semantics, exact rational/interval contracts,
current package names and closed v1 artifacts. Provider identity is additive;
filtrations and channels are not automatically edge metrics. Source/provenance
hashes may change while a regime's descriptor remains invariant.

Use complete fixed components and weights for the initial pseudometric.
Pair-dependent missing-component means are partial diagnostics and may violate
triangle inequality. Null mandatory observations yield indeterminate status;
positive distance does not mean exact indistinguishability. Kernel/History
semantics are reused only through compatible explicit evidence contracts.

The attachment's behavioural-pseudometric authorship is corrected in the adopted
analysis. Its flow floats, schema-v2 example, package name and numeric UI examples
remain sketches rather than silently replacing runtime contracts.

## Consequences

Legacy stages 0–5 remain implemented. Old stages 6–10 no longer define the next
task; the R0–R12 ledger does. Existing schemas and scientific artifacts retain
their original identities. No kernel, source model, runtime API or public page
changes are part of this documentation revision.

Independent computational agreement remains distinct from scientific review.
Zero signature distance is regime-relative observation equivalence, not common
mechanism or a universal law. Negative added-value findings remain publishable
research outcomes and must constrain subsequent claims.
