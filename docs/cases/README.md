# History Case Implementation Documents

Updated: 2026-08-25

This directory contains the canonical implementation document for every
registered history case. Each document defines sources, evidence boundaries,
experiments, negative tests, falsification criteria, and a Definition of Done.
The registry, committed artifacts, and verification results determine whether
a document is a plan or an implemented specification.

Portfolio status and taxonomy placement come from
[`cases/history-case-registry.json`](../../cases/history-case-registry.json),
not from directory names. Start with the
[History Case Portfolio](../history/HISTORY_CASE_PORTFOLIO.md).
