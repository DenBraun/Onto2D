# History Case Implementation Plans

Updated: 2026-08-18

This directory contains the canonical implementation plan for every registered
history case. A plan defines sources, evidence boundaries, experiments,
negative tests, falsification criteria, and a Definition of Done. It is not
evidence that the case has been implemented.

Portfolio status and taxonomy placement come from
[`cases/history-case-registry.json`](../../cases/history-case-registry.json),
not from directory names. Start with the
[History Case Portfolio](../history/HISTORY_CASE_PORTFOLIO.md).
