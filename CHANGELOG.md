# Changelog

All notable user-visible changes are recorded in this file.

## [0.1.0] - Unreleased

### Added

- Dependency-free deterministic Onto2D kernel with 195 published schema-v1
  capabilities and an empty pending kernel registry.
- Canonical graph and skeleton identity, bounded generation, predicates,
  functionals, selection, multi-depth closure, null models, explanations, and
  replayable run artifacts.
- 130 JSON Schema Draft 2020-12 contracts and TypeScript declarations for all
  publishable workspaces.
- Catalogue, scientific-boundary, and verified local run-store adapters.
- Reproducible three-node motif case and three static project studies.

### Fixed

- Normalize kernel-evidence paths before frozen-contract comparison so Windows
  uses the same repository path representation as Linux and macOS.
- Restrict package tarballs to runtime source, documentation, and license
  files.
