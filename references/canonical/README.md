# Canonical reconstruction of the central graph

The active source records what is proposed, what has been checked, and what
remains unresolved. Its scope covers the Level-0 foundation, a bounded optical/retinal pilot and
conditional OFF retinal routing. It does not declare
the theory of arising complexity empirically validated.

## Construction logic

1. Identify a specific assertion, its scope and a source locator. An author's
   definition, a computational result and a published method have different
   evidential roles.
2. Give each concept a stable semantic identifier. Preserve the historical
   `Level.Id` through explicit mappings. A manuscript phase is not derivation
   depth. Local density `rho` and its integral `Gamma`, and a premetric
   context and an analytic metric, require distinct definitions and tests.
3. Separate a trial-field domain from admitted solutions. Represent a rule as
   its own node, retaining its joint premises,
   multiplicities, conditions and output classes. Rule-incidence edges use
   the `descriptive` layer: they describe a specification. They do not assert
   demonstrated physical generation.
4. Separate possible carrier classes from successful instances. Test
   resonance, localization, stationarity and persistence independently. The
   existing expanded numerical case admits no candidate passing every CRT
   objecthood gate.
5. Require an explicit state map and tests of effective dynamics and
   interventions before promoting a new carrier. The methodological reference
   is [Rubenstein et al., UAI 2017](https://arxiv.org/abs/1707.00819v1);
   applicability to CRTs remains to be established.
6. State the candidate universe, target property, allowed removals, cost and
   search bounds for every minimality claim. Predictive minimality in
   [Shalizi and Crutchfield](https://arxiv.org/abs/cond-mat/9907176v2) does not
   establish the minimum number of physical components.

The rules are specifications with obligations. Tools execute source checks,
finite mathematical witnesses and deterministic graph compilation. Physical
rule applications will require a separate contract for instances, measurements
and individual admission outcomes.

An absent edge means that this edition has no adopted justification for that
edge. It does not establish that the corresponding interaction is absent in
nature. Published operating dependencies use `functional-support` with
explicit study contexts; the layer does not certify a physical closure.
The routing extension additionally binds complete experimental comparison
protocols. Shared publication identity is insufficient for combining edges;
shared experimental scope is a prerequisite, not proof of a validated path.
Geometry of the compiled graph describes the adopted representation;
it is not the geometry of physical space.

## Reproduction and revision

The [first-release validation record](../../models/causal-emergence/canonical/VALIDATION.md)
contains its exact artifact identities, checks and scientific acceptance limits.
The [current validation record](../../models/causal-emergence/canonical/VALIDATION-2026.09.12.4.md)
records the dictionary-review release and its verification.
The active edition is `2026.09.12.4`: 50 entities, six rules, 173 claims,
48 descriptive connections and twelve scoped operating dependencies.
The unchanged Level-0 ledger retains 14 descriptions, 13 joint-rule
replacements and 57 withheld assertions. The pilot retains two scoped
assertions, replaces nine and withholds eleven. In total, 30 historical cards
and 106 assertions have internal dispositions; 219 cards and 865 assertions
remain pending. These counts describe internal review, not scientific validation.

```sh
npm run check:canonical
npm run model:causal-emergence:legacy:verify
node models/causal-emergence/canonical/build.mjs --verify --version=2026.09.11
node models/causal-emergence/canonical/build.mjs --verify --version=2026.09.12
node models/causal-emergence/canonical/build.mjs --verify --version=2026.09.12.1
node models/causal-emergence/canonical/build.mjs --verify --version=2026.09.12.2
node models/causal-emergence/canonical/build.mjs --verify --version=2026.09.12.3
npm run case:level-0:verify
```

The canonical check validates the source schema, references, local hashes,
legacy accounting, per-edge dispositions, finite witnesses and exact current
and all five earlier canonical releases. Historical editions are rebuilt from
their hash-bound [source snapshot](../../models/causal-emergence/source-snapshots/README.md)
using their original compilers and the installed project toolchain. The
numerical case command separately reruns the existing solver chain. A
successful schema check or matching hash does not establish the truth of
scientific prose.

For a substantive revision, preserve the preceding source snapshot, update
the source and migration versions, record the reviewed decisions, and run
`npm run model:causal-emergence`. Existing differing releases cannot be
overwritten. Update the registry, its Studio pin, the default loader and
examples after verification. Historical geometry studies pinned to
`2026.08.15` retain their original subject.

The [full work plan](../../docs/ROADMAP.md) includes the remaining manuscript
review, consistent operator/action/dispersion conventions, independent-field
variation and objecthood criteria, tests for the unresolved Level-0 decisions, the
remaining retinal scientific obligations and the remaining legacy levels. Bibliographic additions
must support identifiable assertions, rather than merely resemble node names.
