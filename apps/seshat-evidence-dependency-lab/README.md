# Historical Evidence Dependency Lab

Static Explorer for the approved
`polaris-2026-road-three-polity-v1` Seshat epistemic provenance artifact.

The browser verifies the artifact SHA-256 before rendering:

- the exact native claim and public narrative;
- the claim-local required support DAG;
- source-work fan-out and unavailable public actor/review cuts;
- explicit first categorical flips for supported group types;
- committed raw group-ablation responses;
- pairwise value and exact-support identity comparisons;
- the public metadata and interpretation boundaries.

The artifact also pins Codebook `4.20.2021` and the current CC BY-SA 4.0 Public
Data terms boundary independently from the MIT-licensed Polaris build
repository.

Run the repository site server and open:

```text
http://127.0.0.1:8080/apps/seshat-evidence-dependency-lab/
```

This is a bounded mechanism demonstration, not a ranking of polities, evidence
regimes, source quality, or historical truth.
