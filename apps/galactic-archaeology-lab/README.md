# Galactic Archaeology Lab

Static, light-theme Explorer for the exact
`gaia-dr3-chemical-cartography-interpretation-v1` artifact. It verifies the
artifact bytes in the browser before rendering the 64-source orbit-space view,
quality ablation, evidence-layer ablation, and bounded candidate historical
interpretations.

Run the repository site server and open:

```text
http://127.0.0.1:8080/apps/galactic-archaeology-lab/
```
