# Level-0 Numerical Validation

This static page presents the frozen Level-0 numerical case as an interactive
evidence view. It loads the integrated and Phase-C objecthood artifacts directly;
the browser does not recompute or reinterpret the scientific result.

Run the repository site and open the page:

```sh
npm run dev:site
```

```text
http://127.0.0.1:8080/apps/level-zero-validation/
```

The plotted pulse is the independently checked continuum reference profile.
The plateau curve is a disclosed shape guide. Exact decisions and displayed
metrics come from the frozen solver artifact.
