    Identity policy

    What counts as structure?

    Ignored representationLabels & input order

    Node order, edge order and display names do not enter the canonical candidate bytes.

    6 node permutations x 6 edge orders -> one ID
    Structural relationDirection

    Reversing one arrow changes the directed isomorphism class from feed-forward loop to cycle.

    0f578d7e... -> 913c5005...
    Structural vocabularyEdge role

    Roles are declared semantics. Changing one role produces a new candidate even on the same skeleton.

    0f578d7e... -> 2a7015ba...

    Why this matters

    Closure needs stable objects.

    If the same structure acquired a new identity whenever a caller reordered JSON, censuses, cohorts, rankings and later-depth closure would depend on serialization accidents. Canonical identity removes that degree of freedom before scientific interpretation begins.
