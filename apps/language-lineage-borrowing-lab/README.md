# Language Lineage & Borrowing Lab

This light-theme Explorer loads one exact, hash-pinned Historical Linguistics artifact and explains the case through published genealogy, lexical forms, horizontal borrowing, regime-relative equivalence, and explicit analysis boundaries.

Serve the repository with `npm run dev:site`, then open `/apps/language-lineage-borrowing-lab/`. The page requires same-origin JSON and verifies the artifact SHA-256 before rendering.
