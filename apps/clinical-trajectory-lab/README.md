# Clinical Trajectory Lab

The Lab renders the exact source-locked Clinical Trajectories artifact. It lets
the reader switch among five deidentified aliases, compare each 24-hour
four-lab observation frame with its longer record history, inspect source-row
locators for timeline events, and examine the bounded P04/P05 similarity result.

The browser verifies the artifact byte hash and approved case/source identities
before rendering. It performs no diagnosis, prognosis, treatment
recommendation, treatment-effect estimation, or live clinical lookup.
