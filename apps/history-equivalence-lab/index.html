          06 / How to use this

          Pick identity at the question's resolution

          Distribution check

          Use byte-output equivalence to ask whether a rebuild produced the exact specified artifact.

          Review and audit

          Use inputs, toolchain, environment, or provenance when the route to those bytes matters.

          Never collapse the records

          An equal verdict creates a regime-local equivalence class. It does not erase either execution event.

          Evidence boundary

          Direct

          Source bytes, four execution records, reported runtimes, and produced artifact bytes.

          Derived

          Projection identities, differing-field lists, and the fifteen pair/regime verdicts.

          Excluded

          The session label is recorded but does not participate in normalized environment identity.

          Unknown

          Cross-machine, non-Darwin, other-runtime reproducibility, and builder trustworthiness.

          Methodology: official Reproducible Builds definition, environment perimeter, and SOURCE_DATE_EPOCH specification. This bounded fixture is not a claim about arbitrary software.
