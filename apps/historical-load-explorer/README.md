# Historical Load Explorer

Dependency-free interface for the illustrative finite-path quantity
`dH(x | F) = aF - a0`.

The disclosed examples are evaluated in the browser. They are not kernel run
artifacts, solver outputs, or empirical results. The pure toy model is in
`model.js`; `app.js` renders it.

From the repository root:

```sh
npm run dev:site
```

Open `http://127.0.0.1:8080/apps/historical-load-explorer/`.
