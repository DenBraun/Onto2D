Interpretation

What does the number mean?

Standard assembly asks for the shortest construction of x. Historical load asks how much longer that construction becomes when inadmissible intermediates are removed.

Unit of comparison: one declared construction transition. The result compares minima inside the finite candidate set shown by this prototype; it is not a universal physical timescale.

The essential distinction

The microstructure is unchanged.
Reachability is not.

Historical load is not an intrinsic label attached to a structure. It is a result of pairing that structure with a declared admissibility regime.

Methods / prototype

What is being computed?

Each example declares a finite set of candidate construction paths. A path has an assembly length and a list of predicates it violates.

  1. 01

    Find a0. Select the shortest path before filtering.

  2. 02

    Apply F. Remove every path that violates an active predicate.

  3. 03

    Find aF. Select the shortest surviving path, if one exists.

  4. 04

    Subtract. Report dH(x | F) = aF - a0.

Prototype boundary

The dH instrument is an interface demonstrator. It does not load a verified Onto2D run artifact or implement a scientific solver. Its four target cases are illustrative finite path spaces.

The frozen empirical network-motif study is deliberately published as a separate Explorer and does not enter this calculation.
