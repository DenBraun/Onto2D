# in-toto Admissibility Explorer

Light-theme, artifact-verified Explorer for the bounded in-toto v1.0 case.

Serve the repository root and open `/apps/in-toto-admissibility-explorer/`.
The page verifies the committed case artifact by exact SHA-256 before rendering
declared policy, actual signed links, native and optional policy verdicts,
counterfactual routes, or Historical Load.
