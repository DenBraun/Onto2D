# Artwork Provenance Identity Lab

Light-themed, source-locked Explorer for the Getty Artwork Provenance case. It verifies the exact artifact bytes in the browser before rendering the four-object cohort, A1983 timeline, source records, evidence gap, five history-equivalence regimes, and undefined Historical Load boundary.

Serve the repository with `npm run dev:site` and open `/apps/artwork-provenance-identity-lab/`.
