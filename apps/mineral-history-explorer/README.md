# Mineral Formation History Explorer

The light-theme Explorer verifies and loads the frozen Mineral Formation
History artifact. It provides:

- regime switching across species, sample, and published-formation identity;
- a complete ten-sample cohort inspector;
- exact evidence cards for the three reviewed published interpretations;
- descriptive per-sample trace-element series with no auto-classification;
- explicit unresolved mappings and an undefined Historical Load boundary.

Open `/apps/mineral-history-explorer/` through the repository web server.
