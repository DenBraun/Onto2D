Evidence boundary

What this case establishes

The fixture uses real Git object construction and native IDs. It establishes state/history separation inside a bounded deterministic repository. It does not claim that commit ancestry is causality, and it introduces no Historical Load value.

  • Fixture code fixes actors, messages, timestamps, trees, and parent order.
  • Git writes every blob, tree, and commit through plumbing commands.
  • An independent implementation recomputes the SHA-1 object framing.
  • The browser verifies the exact committed artifact SHA-256 before rendering.
Case overview

State identity is a declared regime, not a universal fact.
