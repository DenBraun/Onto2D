# Cell Lineage Identity Lab

The light-theme case explorer loads the frozen Cell Lineage Identity artifact,
checks its exact byte length and SHA-256 in the browser, then exposes:

- the four identity-regime class counts;
- all 56 source transcriptomic clusters;
- bounded cluster -> observed HMID -> targets 1-4 signature relations;
- exact cross-regime pair counts and source-row examples;
- partial target coverage and the undefined Historical Load boundary.

The relation map uses arrowheads, fixed rounded nodes, wrapped/clamped labels,
and a bounded scrolling canvas. Its derived edges do not represent observed
cell divisions, and target position is never presented as edit time.
