# Onto2D History Atlas

The History Atlas is the primary portfolio view over
[`cases/history-case-registry.json`](../../cases/history-case-registry.json).

It renders:

- the Recorded / Embodied / Reconstructed by Identity / Present State / Future
  matrix;
- hybrid membership without moving or duplicating cases;
- filters for mode, effect, domain, evidence, maturity, Historical Load, and
  Model Pack availability;
- one status-honest detail card per case.

The application does not contain an independent taxonomy. Classification,
maturity, document paths, Model Pack paths, and Explorer paths come from the
validated registry.
