# `@onto2d/catalog-adapter`

```sh
npm install @onto2d/catalog-adapter
```

This adapter reads and audits the preserved `scr/level-*.json` catalogue
without modifying it. For caller-supplied reviewed inputs it can also replay:

- relation-classification views and adjudicated projections;
- post-unblinding amendments;
- node resolution and loss-preserving SCC condensation;
- reconciliation diagnostics, migration metrics, explanations, and cluster
  concentration.

The adapter never treats every `ParentCode` edge as generative and never infers
a node disposition from a desired topology. Upstream artifacts and every
source node/relation are verified before projection.

Policy authorship, annotation collection, and reviewed migration data for the
current catalogue remain external work. The implemented replay machinery is
not evidence that those scientific decisions have already been made.
