# Airflow Dependency Constraints Model Pack

Build and verify the exact external release:

```sh
npm run model:airflow-constraints
npm run model:airflow-constraints:verify
```

The compiler maps the source-locked constraint record, 17 projects, 24 exact
release candidates, 64 complete bounded solutions, three Historical Load
profiles, and eight Onto2D-only constraint ablations. Resolver diagnostics and
counterfactuals remain separate from upstream evidence and path cost.
