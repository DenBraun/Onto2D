# Legal Precedent History Model Pack

This exact Model Pack compiles the bounded Legal Precedent case into separate
source, native-citation, availability, attributed-treatment, counterfactual,
provider-disagreement, and evidence-boundary layers.

The pack contains 16 `cites` edges and zero binding-status claims. Four
normative treatment nodes remain attributed to exact locators in the official
`Green` opinion. CourtListener citation counts are display-only metadata;
GovInfo decision dates drive the time slice; later opinions never become
inputs to the 1968 context.

Build with `npm run model:legal-precedent` and reproduce the committed release
with `npm run model:legal-precedent:verify`.
