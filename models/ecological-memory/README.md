# Ecological Memory Model Pack

This source-locked Model Pack compiles the NEON SOAP before/after analysis into
separate, queryable evidence layers.

- Native source locks, measurement projections, surveys, event records,
  published interpretation, analyses, and non-claim boundaries remain distinct.
- Recorded event precedence compiles as temporal context and never as causation.
- The four-quantile projection does not become full ecosystem state.
- Equality after 0.1 m rounding does not create exact measurement, ecosystem,
  or history identity.
- Different survey sensors remain an explicit protocol change.
- No causal effect, recovery trajectory, future prediction, or scalar
  Historical Load is produced.

Build with `node models/ecological-memory/build.mjs`; verify the committed
release with `node models/ecological-memory/build.mjs --verify`.
