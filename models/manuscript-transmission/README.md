# Manuscript Transmission Model Pack

This source-locked Model Pack compiles the bounded Manuscript Stemmatics case into queryable evidence layers for Model Studio.

- Recorded witness readings do not create ancestry.
- Exact selected-site agreement is explicitly selection-biased and non-evidentiary for copying.
- Copying and correction-source relations are attributed to Robinson's published analysis, never represented as direct observations.
- The unresolved better copy remains an unresolved reference.
- The correction source into Cx2 remains a non-tree-compatible contamination relation.
- Historical Load remains `null`, because the case defines no finite route space, admissibility rule, cost functional, or baseline route.

Build with `node models/manuscript-transmission/build.mjs`; verify the committed release with `node models/manuscript-transmission/build.mjs --verify`.
