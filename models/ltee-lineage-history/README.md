# LTEE Lineage History Model Pack

This compiler maps the exact Ara-3 citrate replay case into a graph with separate source, generation-background, replay-protocol, observation, published-statistic, interpretation, discrepancy, and boundary layers.

The graph creates no genealogical or causal edges. It never pools protocols, promotes non-observation to impossibility, treats generation as genotype, silently repairs the replay-2 expected-mean discrepancy, or computes Historical Load.

```sh
npm run model:ltee
npm run model:ltee:verify
node --test models/ltee-lineage-history/compiler.test.mjs
```
