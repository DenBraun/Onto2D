# Language Transmission Model Pack

This exact Model Pack compiles the source-locked Historical Linguistics case into independent published-classification, lexical-record, horizontal-transmission, similarity, and equivalence-analysis layers.

The pack intentionally contains zero genealogical borrowing edges and zero cognacy assertions. WOLD borrowing records point to one donor reference and one target form; they never point from a donor language to a recipient language using the Glottolog parent relation. Surface comparisons are non-evidentiary nodes.

Build with `npm run model:language-transmission` and reproduce the committed release with `npm run model:language-transmission:verify`.
