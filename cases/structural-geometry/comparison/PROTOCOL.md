# Strict comparison controls, version 1

Frozen on 2026-09-07 before comparison result generation. These are declared
computational controls, not empirical ground truth or external review approval.

Use the existing typed source fixtures and their verified Causal Emergence
fragment. Add only the two three-node stars in `controls.json`, with uniform
declared edge types. Do not change the earlier graph, dictionary, mapping,
observation or reference files. Each pair lists the regimes tested before its
outcome is computed. Source scopes retain all induced edges and isolates.

Expected qualitative controls:

- Self, relabeling, presentation annotations and set ordering preserve complete
  graph values under permitted vocabulary alignment.
- The outward/inward-star pair merges under all seven topology summaries and
  splits under exact directed structure and jointly typed structure.
- The correlated/crossed typed pair merges under untyped structure and topology
  but splits under one common five-field matching.
- Missing typed fields, incompatible dictionaries, absent mapping approval and
  uncovered mapping values yield indeterminate typed comparisons. An existing
  untyped difference remains a diagnostic when the typed component is missing.
- Approved renumbering restores comparable typed values. The same source with
  a smaller scope can have complete different observations.
- Caller-declared unavailable/rejected evidence removes only its component's
  comparison coverage. Other comparable differences survive. All seven missing
  summary-use declarations produce 0/7 incomplete coverage, never equality.
- A missing typed field and a rejection can coexist; preserve both reasons.
- The unchanged real-source fragment contributes self and explicit unequal-scope
  comparisons, without a cross-source scientific equivalence claim.

Synthetic identity mappings explicitly pair code values 0, 1 and 2 and each
role/necessity with itself. Renumbering and partial declarations reuse the old
typed control mappings. A fixture's `approve` flag represents the test caller's
predeclared allowance; a mapping's metadata cannot self-approve it. Evidence-use
restrictions also bind this protocol as synthetic caller declarations. None of
these flags establishes external review or a real domain vocabulary mapping.

The independent Python reference enumerates directed graph permutations and
uses independent Boolean matrix closure for the topology profile. It applies
declared type maps and use restrictions to those source-derived values, then
computes component equality, reasons, family coverage and the strict result.
It imports no production comparison/evaluator implementation and reads no
production artifact when writing expected results. Verification additionally
checks the stored comparable values belong to the independently derived graph
orbits, so matching statuses alone cannot hide an incorrect graph descriptor.

The JS builder must verify all reference source hashes and each independent
result before writing any output. Check and report modes are read-only.
Disagreement is a failed gate; do not tune these pairs or mapping approvals to
obtain a preferred status. New research claims require a separate protocol.
