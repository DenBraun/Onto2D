## Synthetic controls

[graphs.json](synthetic/graphs.json) contains 16 small declared graphs. Their
edges are constructed controls, not observations. The package tests wrap each
graph in a synthetic Model Pack with an explicit `source-parent` relation layer.
No domain annotation is inferred from node names.

[reference.py](synthetic/reference.py) independently enumerates edge incidences
for the unit specialization of equation (5) in
[Saucan et al.](https://arxiv.org/abs/1809.07698).
[expected.json](synthetic/expected.json) freezes its per-edge and per-node values.
The paper-edge-neighborhood fixture reproduces the contributing neighborhood
of edge `1->2` (curvature -4), not every edge in the published figure.

```sh
python3 cases/structural-geometry/synthetic/reference.py --verify
node --test packages/structural-geometry/test/*.test.mjs
```

Regeneration requires `--write`; check commands never rewrite expected data.
The reference uses Python's standard library and no JavaScript subprocess,
package API or production degree-counter implementation. It is separate code
authored in this milestone, not independent reviewer approval.

## Full Causal Emergence snapshot

[source-lock.json](causal-emergence/source-lock.json) pins model ID, version,
semantic root and manifest of the existing 2026.08.15 release. The
[projection](causal-emergence/projection.json) includes all 249 nodes and 971
edges with exact source record traces. The
[artifact](causal-emergence/artifact.json) includes the unit curvature census,
level/relation summaries and exact identity of every policy and algorithm.
The [result reading guide](RESULTS.md) summarizes the numbers and local checks.

```sh
npm run structural-geometry:check
npm run structural-geometry:report
```

The check replays frozen bytes from the source pack, compares the full graph
against the Python reference, validates schemas, and runs the behavioral tests.
The report verifies stored results before printing counts, distributions,
necessity summaries and extrema. No web server is required to test this stage.

Generation is `npm run structural-geometry:build`; inspect the resulting diff
before accepting changed results. The source lock is never regenerated by that
command. The source snapshot retains its `source-snapshot-known-findings`
status. Source weights and scientific annotations are preserved, and its
parent relations are not upgraded to reviewed causality.

Read the [definition and limits](../../docs/structural-geometry/GEOMETRY.md#metric-and-algorithm-policies)
before interpreting signs or comparing values. These cases are separate from
the History Matters predictive benchmark and do not add to its score or cards.

The later [typed metric suite](experiments/README.md) and
[certified Ollivier suite](ollivier/README.md), and
[normalized shadow flow suite](flow/README.md) have separate contracts and frozen
artifacts. The [nine-run flow supplement](flow-controls/README.md) adds independent
star/bridge expectations without rewriting the original flow suite. The combined
geometry check verifies all four computational paths and this supplement.
