# Immutable sandbox controls, version 1

Fixed on 2026-09-07 before result generation. These are graph-operation controls,
not observed scientific responses, invariance passes or empirical interventions.
The sandbox contract and every earlier regime/observation/comparison suite remain
separate. Do not change earlier graph declarations or accepted artifact bytes.

Reuse declared canonical/typed fixtures for a path, reciprocal pair, outward star, edgeless
graph, missing typed field, reordered typed sets and a source-bound Causal fragment.
Add a mixed reciprocal/path graph, a five-node boundary graph with an isolate,
and a 32-node directed cycle exercising 32 exhaustive targets and 1,024 edge visits.

Predeclared expectations:

- Identity retains the graph and every isolate, including an edgeless graph.
- All-edge removal produces no edges and preserves all nodes. Each-edge removal
  produces independent one-edge deletions, never accumulated deletions.
- All-edge reversal reverses directed endpoints simultaneously, preserving
  source/shadow mapping and typed annotations. Reversing a reciprocal pair in
  full remains valid; reversing either member alone is rejected as a parallel edge.
- A mixed reciprocal/path graph retains both rejected and applied singleton
  reversal targets. Rejected targets have no fabricated output graph.
- Empty removal/reversal targets are unavailable, with zero runs and zero work.
- Typed fields remain jointly attached to their source edge; sets are normalized,
  missing fields remain absent, and no causal meaning is automatically recoded.
- Induced scope retains internal edges and isolates and accounts for incoming,
  outgoing and external boundaries. Transformations affect only internal edges.
- Every eligible edge is selected, including symmetric ties. Relabeling transports
  the entire target/result set; source-ID order is serialization only.
- The 32-edge cycle produces every target within the fixed budget. A 33-target
  request must fail without returning a truncated or sampled result.

The independent Python reference reconstructs source-ID mappings and applies
set-based edge deletion/reversal separately to every baseline target. It does
not import JavaScript or read production artifacts while generating expectations.
Enumerate all 69 loopless directed graphs on one through three nodes under five
requests (identity, all/each removal, all/each reversal), retaining empty-target
and reciprocal-conflict outcomes. This census tests the transformation substrate,
not response significance. Source, protocol and reference dependency hashes
must match before the JS builder compares every result and writes any artifact.

New target families and scientific classifications belong to SG2-021/022 and
must be fixed before measuring responses. Do not promote an identity copy or a
completed batch into a successful invariance or distinguishability result.
