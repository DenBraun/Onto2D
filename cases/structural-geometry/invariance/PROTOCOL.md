# Structural invariance controls v1

This protocol fixes SG2-021 before production results are generated. It extends
the immutable sandbox with measured representation controls; the sandbox v1,
three regime definitions and their preparation artifacts remain unchanged.

Every request executes four mandatory, separately registered invariance probes
against the same verified, scoped baseline: reverse record/key serialization;
rename every node with a reversed ordinal in a fresh namespace; rename every
edge likewise; replace synthetic labels, positions, colors and viewport zoom.
All records participate. Ordinals serialize exhaustive mappings; they select no
preferred node, edge or structural role. Empty edge renaming is an explicit
no-op control, not evidence that an edge was exercised.

The harness retains exact JSON payload strings, including key/record order and
presentation. A private adapter parses each payload afresh and invokes the
existing canonical, topology or joint typed graph evaluator. Presentation is
excluded only at this declared adapter boundary. This tests that boundary, not
the website renderer or arbitrary Model Pack serialization. Source manifests,
scope boundaries and dictionary context are retained as provenance. Transformed
representations are never Model Packs and never acquire the source identity.

Compare every mandatory observable in regime order. Exact complete agreement
passes; a complete difference fails; any missing mandatory value makes the probe
indeterminate, retaining observed differences. Equal missing values never pass.
The suite uses the same strict rule across all four probes. Vocabulary codes
remain inside one source context; this does not authorize cross-source mappings.
No custom callbacks, probe selection, source-ID target selection or partial score
are supported. Errors produce no partial artifact. Limits: five representations,
five observation evaluations, at most ten bounded canonicalizer calls, 500,000
canonical entries and 4 MiB cumulative/final output. Existing regime bounds apply.

Controls reuse declared sandbox sources: chain, star, reciprocal typed pair,
isolates, missing typed data, reordered type sets, mixed directed graph, induced
boundary with isolate, opaque IDs and the six-node Causal Emergence scope. Add
singleton, complete six-node typed graph, and the topology limit of 64 nodes and
256 edges. No source or graph is chosen from a measured outcome.

Independent Python expectations use exhaustive bijections for untyped and joint
typed equality, and Boolean transitive closure for topology. The reference reads
only source controls and this protocol, never production outputs to generate
expectations. Bind every input file and reference dependency by SHA-256.
Exhaust all 69 loopless directed graphs on one to three nodes in all three
regimes, with complete fixed typed annotations, through the four transformations
(207 requests, 828 probe results). Verify actual mappings and payload changes as
well as independently measured equality. Additional destructive controls remove
an edge or change a typed field: these must register a difference, but are never
entered into the invariance registry. Missingness aggregation is checked
independently across all profiles of equal/different/missing components up to
seven entries, including empty profiles.

Freeze and verify independent expectations before writing golden artifacts.
Browser replay, source/scope tampering, malformed contracts, immutable inputs,
budget boundaries, source relabeling and engine opt-in are acceptance checks.
Passing this finite suite is computational agreement for these controls, not a
proof that arbitrary implementations or all representations are invariant.
Response probes, History adapters, response signatures, pseudometrics,
conditional graph abstractions and the Structural Geometry page remain later
tasks. Failed probes cannot be reclassified after observing their outcomes.
