# Level-0 oscillator case

This directory is the research case package for the foundational Level-0
theory. It currently freezes source identities only; it does not yet
claim that the paper's resonant triad has been implemented or validated.

The computational decomposition, equation traceability, admissibility gates,
and limitations are documented in
[Foundational Paper Analysis](../../docs/FOUNDATIONAL_PAPER_ANALYSIS.md). The
implementation sequence and acceptance gates are in
[Kernel Development Plan](../../docs/KERNEL_DEVELOPMENT_PLAN.md).

`source-lock.json` is deliberately machine-readable and contains only source
artifacts stored in the repository.
